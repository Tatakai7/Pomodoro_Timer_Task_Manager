# 🍅 Pomodoro Timer & Task Manager  

> Stay focused. Manage your time. Get things done — beautifully.  

A sleek and minimalist productivity app that combines a **Pomodoro Timer** with a **Task Manager**, built using **React**, **Vite**, **Tailwind CSS**, and **Lucide React icons**.  
Perfect for boosting focus, organizing your to-dos, and maintaining healthy work rhythms — all in one elegant interface.  

---

## 🌟 Features  

- ⏱️ **Pomodoro Timer** — Stay productive using 25-minute focus sessions with short breaks.  
- 📝 **Task Manager** — Add, edit, and mark tasks as complete with ease.  
- 🎨 **Clean UI** — Tailwind-powered responsive design with Lucide React icons.  
- 🔄 **Progress Tracking** — Track completed Pomodoros and total sessions.  
- 💾 **Local Storage Support** — Your tasks and progress persist even after refresh.

## 🕹️ How to Use
1. Add your tasks — Write down what you need to accomplish.
2. Start the timer — Work for 25 minutes without distractions.
3. Take a break — Relax for 5 minutes before your next session.
4. Repeat & achieve — Stay consistent, build focus habits, and watch your task list shrink.
   💡 Tip: Adjust work/break durations (if available) to fit your productivity rhythm.

## ⚙️ Installation  

### 1️⃣ Clone the Repository  
```bash
git clone https://github.com/Tatakai7/Pomodoro_Timer_Task_Manager.git
cd pomodoro-timer-task-manager

2️⃣ Install Dependencies
npm install

3️⃣ Install Lucide React (for icons)
npm install lucide-react

4️⃣ Run the App
npm run dev

Then open 👉 http://localhost:5173 in your browser.
